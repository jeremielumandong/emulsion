# Bundled UI fonts

Unmodified Geist and Geist Mono variable TTFs from Google Fonts, pinned to
commit `718e1db4deb9e4d9d85a0ead1b9f5fde2761ccfd`:

- `ofl/geist/Geist[wght].ttf` → `Geist.ttf`
- `ofl/geistmono/GeistMono[wght].ttf` → `GeistMono.ttf`

Source: https://github.com/google/fonts/tree/718e1db4deb9e4d9d85a0ead1b9f5fde2761ccfd/ofl

Copyright 2024 The Geist Project Authors. Both fonts use the SIL Open Font
License 1.1; their original license files are included beside them. Font data
is embedded in the native application and registered with GPUI at startup;
there is no runtime download.
