# Bundled spelling dictionaries

`en_US.aff` and `en_US.dic` are the unmodified `index.aff` and `index.dic` of
the npm package `dictionary-en` 4.0.0 (https://github.com/wooorm/dictionaries),
which packages the SCOWL-derived en_US Hunspell dictionary, version
2020.12.07 (http://wordlist.aspell.net). Its license text is
`en_US-LICENSE.txt` (MIT AND BSD). The dictionary is embedded in the
application for caption spell checking; there is no runtime download.
