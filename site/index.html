FOR PHOTOGRAPHERS

Develop the photo.
Keep the original.

Open supported camera RAW files and work from sensor data. Tune exposure, temperature, tint, shadows, contrast, saturation, and highlight rolloff before bringing the image into your composition.

  1. Start with Auto tone, Pick neutral white balance, or the camera’s as-shot white balance.
  2. Refine luminance curves and inspect your changes with the draggable before/after divider.
  3. Save development settings in an Emulsion JSON sidecar, or save an ORA project for layers and history.

RAW camera support varies. Keep the original RAW alongside its sidecar or linked project; ORA does not embed the source.

01 / Getting started

Emulsion is an actively developed desktop image editor built in Rust with GPUI for Linux, macOS, and Windows. Its original code is MIT licensed. Painting and editing work without an AI account.

Build from the repository using the instructions for your platform. Linux requires Rust, the GPUI system libraries, and a working graphics driver; Windows requires the MSVC Rust toolchain and Visual Studio C++ Build Tools; macOS packaging requires Rust and the standard icon tools.

Open an image, reopen a recent project, or open the Home screen’s … menu and choose New transparent canvas. Save layered work as .ora; use Export to create an image for sharing.

Linux also has a local Flatpak build via scripts/build-flatpak.sh, requiring Flatpak and flatpak-builder. Its sandbox cannot use converters installed on the host. The Windows command builds an executable; add -Package after installing the documented packaging tools for an NSIS installer. Local Windows builds are unsigned; macOS packages are signed ad hoc for local use.

02 / Painting, retouching, and layers

Choose a tool on the left and adjust its options above the canvas. Use brushes and erasers for painting, clone and heal for retouching, or smudge, gradients, and liquify to reshape the image. Add a selection or mask when an edit should affect only part of the artwork.

The right dock includes Layers, Channels, and Paths. Use Ctrl + Shift + N (Cmd + Shift + N on macOS) to create a transparent layer; F7 opens Layers. Add groups, duplicate layers, and combine raster artwork with editable text and paths. The layer controls and Properties panel hold transforms, blending, and masks; use Window → Properties to open that panel.

Choose Grade (Shift + Q with the canvas focused) for exposure, curves, colour balance, and hue/saturation adjustment layers. Select an existing adjustment layer to edit its controls. Add references through the Ref (Reference) panel to keep an image beside your canvas; references belong to the open session and must be reattached after reopening.

Brush Library and Brush Studio

Open Brush library from the Presets sidebar to browse, search, pin, and organize brushes into sets and libraries. Double-click a brush or choose Brush Studio to edit its settings, shape and grain sources, or dual components. Try strokes on the Studio pad; Done publishes the draft and Cancel discards it without painting your document.

Native .embrushes packages retain editable settings and source assets. Imported .brush, .brushset, .brushlibrary, and supported sampled-tip .abr files are conversions with format-specific limits; they do not promise identical brush behavior or complete archive compatibility.

Brush Library and Studio guide → Brush import limits →

Move and align artwork

Choose Move (V) to drag a selected layer or group. With the canvas focused, arrow keys nudge by one document pixel; Shift+arrow nudges by ten. These move artwork, while Hand and Rotate View change how you look at the canvas.

03 / Developing and saving RAW photos

Open a supported RAW file to develop its sensor data. Use Adjust for tone and white balance, Curve for presets and five editable luminance points, and Settings for presets, sidecars, camera defaults, and selected-photo synchronization.

Choose Before / after in RAW Properties to compare as-shot development with your edits using a draggable divider. With the canvas focused, Left/Right and Home/End move the divider; Escape closes comparison.

For a directly opened RAW photo, Save writes <filename>.emulsion-raw.json beside the source without modifying it. Reopening the original restores these settings. Sidecars contain the current RAW recipe, not history, and are not Adobe XMP. Keep them with the original when moving or backing up photos; rename the sidecar to match if you rename the photo. An invalid or mismatched sidecar produces an error instead of silently dropping your saved settings.

Use Save as → .ora to preserve layers, history, and versioned RAW settings. Keep the original: the project stores a verified link, not an embedded RAW. If it has layers or named versions that a sidecar cannot preserve, Save also asks for a project. Use Locate original… if an identical source has moved. The project can reopen without its original, but changing RAW settings or exporting the linked RAW layer requires it. Painting directly on that layer detaches its RAW recipe; use a separate layer for retouching. If Save or Export reports that RAW development is still running, wait for the preview to finish and retry.

The working raster is 16-bit linear RGB, not a wide-gamut floating-point document. Monitor-profile conversion, lens profiles, advanced RAW noise reduction, and saturated-highlight reconstruction are not included in this development path.

04 / Recipes and batch export

Open the dock’s Panels menu and choose Recipes. The Emulsion collection holds starter recipes, camera presets, and saved looks. Other collection chips open the community library, grouped by film simulation family. Use tags to narrow a collection; each library recipe retains its creator and source in its notes.

In Batch, choose a folder in the top bar and select photos in the left pane. Search the recipe chooser by name or tag, or expand Category for a filter. Set the format and output folder in the right dock, then select Export in the top bar.

Use Fit image and the − / + controls to navigate the preview. Drag or scroll to pan; Ctrl/Alt/Cmd+scroll or pinch zooms around the pointer. Double-click to fit again. Preview zoom uses a rendered image up to 1100 pixels; export retains its own output settings. Selecting another photo resets the view; changing the recipe keeps the view for that photo.

05 / History, project files, and replay

Use undo, redo, and history branches to explore alternatives. Save an OpenRaster (.ora) project to retain editable work and history. Emulsion’s native data keeps text and paths editable; other OpenRaster readers can use the included layer previews. Newly saved native version 2 projects require an updated Emulsion build for native editing.

Open the dock’s Panels → Timeline, then choose Replay drawing to play the picture back from its history and export a GIF. Leaving Timeline stops playback and returns to the full document.

Export is a delivery step; keep an ORA project when you want to return to editable work. RAW sidecars only preserve development settings, so use ORA when your work needs layers, named versions, or undo history.

06 / Bringing files in and sending them out

Common formats and what to expect
WorkflowFormats and support
Editable projectsSave native work as ORA. Open layered PSD/PSB and supported 8-bit GIMP XCF files. Import fidelity depends on the source features.
Photos and artworkOpen PNG, JPEG, WebP, TIFF, BMP, GIF, SVG/SVGZ, JPEG XL, OpenEXR, and more. Camera RAW support varies by camera, model, and compression. Nikon HE/HE★ decoding is experimental, with approximate colour and tone reconstruction.
Common exportsPNG, JPEG, WebP, and TIFF; PNG/TIFF support 16-bit output. Linked RAW exports offer sRGB or Adobe RGB profiles and full, half, or quarter sizes. Choosing Adobe RGB does not recover colours already clipped in the sRGB working document.
Layered exportsLayered PSD and 8-bit XCF. XCF exports visible top-level layers with adjustments, masks, and styles baked into each layer; hidden layers are omitted.
Extra convertersHEIC/HEIF, AVIF, PDF/PostScript import, and other formats can use installed external converters. AVIF, HEIC, JPEG XL, and PDF export also require external tools. Flatpak cannot use host converters.

CMYK sources are converted to RGB for editing, with support depending on format and profile. CMYK PSD/PSB support is limited to the saved merged appearance for supported 8-bit files. Projects and exports retain RGB pixels, not CMYK ink separations. Formats without transparency composite over white.

07 / Optional assistant and image generation

An assistant that uses editing tools

Install and authenticate a supported Claude Code, Codex, OpenCode, or Kimi Code CLI, then click Ask AI or press F1 (or Alt + F1) to open the Ask bar and select Assistant. Ask it to inspect the canvas, use a reference, build artwork, adjust colours, or automate a recipe. Review proposed document changes with Apply/Skip. Model access or a provider subscription is not bundled.

Emulsion connects its MCP server to the active app so the assistant can call editing operations directly. A connected MCP client lists the current catalog with tools/list. Starting emulsion mcp-serve alone still answers that request but cannot edit an open document without the app connection.

Generate an image or fill a selection

Open Settings with Ctrl + K (Cmd + K on macOS) and configure Image generation, then choose Local SD, OpenAI, or Google in the Ask bar opened by Ask AI or F1. Local SD uses an A1111/Forge API server. Cloud providers require their own API keys and separately billed access. Enter a prompt; generated results arrive as labeled raster layers you can hide or undo. With an active selection, generation uses the surrounding canvas as context.

Environment API keys take precedence over saved keys: OPENAI_API_KEY for OpenAI, and GEMINI_API_KEY before GOOGLE_API_KEY for Google. Cloud generation sends prompts and fill context to the selected provider. Save & test checks key/model access, not generation quota. A Google free_tier error with limit: 0 needs a billing or quota change for that API project; waiting for a retry timer does not add quota. Cancelling discards the result but does not guarantee cancellation of provider processing or charges. Attached references are available to Assistant; image modes use the prompt and selected canvas context.

Optional subject selection, background removal, inpainting, face restoration, and upscaling require the relevant models or providers to be configured.

08 / Workspace and shortcuts

Use the sun and moon buttons in the top bar to choose light or dark mode. On Linux, select ◆ Omarchy in the top bar to follow your active Omarchy theme. Emulsion picks up theme changes live while it is running and shows the theme’s name in the control. No hooks or system configuration changes are needed. Choose the sun or moon button to return to Emulsion’s built-in light or dark palette. The canvas surround stays neutral, and theme changes never alter your artwork’s pixels. The current interface uses compact chrome; switch between Photo and Draw from the top bar.

Use the dock’s Panels menu for Navigator, Info, Recipes, Timeline, History, or Histogram. The Window menu also opens Properties, Adjustments, History, Info, Layers, Channels, and Paths. Tool buttons support Tab navigation and Enter/Space activation. Focused sliders accept arrows, Shift+arrow for larger steps, and Home/End for limits.

These are the default editor shortcuts. On macOS, Ctrl-based shortcuts also accept Cmd; Alt is the Option key. Bare tool keys apply when the canvas has focus; text fields retain typing behavior. Batch uses its own preview controls described above.

09 / Help and further guides

The documentation index separates current user guides from dated reports and plans. Use the current guides for feature behavior; a backlog or benchmark report is not a promise of supported features.

Recover work and find your files

Home lists recovery copies left by other sessions and offers Open or Discard. Autosaves are recovery copies, not a replacement for saving your project. Settings, shortcut overrides, recipes, brush libraries, and recovery files live in Emulsion’s application data directory; its location depends on the platform and environment.

The files, folders, and environment guide covers paths, backups, command-line options, installer flags, and log capture. Saved API keys are unencrypted in settings.json; remove them before sharing that file with a bug report.

When something does not work

Use the troubleshooting guide for missing converters, RAW sidecar or original-file errors, undetected assistant CLIs, generation quotas, theme issues, and startup failures. For an undetected CLI, Settings offers a provider path field, use path, and detect again.

On Linux, a machine without usable hardware graphics needs an installed software Vulkan driver. Windows can fall back to WARP; macOS has no software fallback. GPU brush painting is experimental and opt-in. See the dedicated guides for renderer and compute controls.
