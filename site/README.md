# Emulsion website

A responsive marketing site for the Emulsion desktop image editor. Built with Vite, vanilla JavaScript, and CSS. Product artwork and screenshots are served locally; Google Fonts has system fallbacks.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy `dist/` to a static host. The site includes a keyboard-accessible feature tour, illustrative colour previews, screenshot lightbox, and platform-specific build instructions. Installation links point to the application repository; no binary availability is assumed.

Product source: https://github.com/jeremielumandong/emulsion
