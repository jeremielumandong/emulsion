# Library and Develop implementation ledger

This ledger tracks the requested desktop Library/Develop layout and the feature audit. A check requires working UI, shared renderer/persistence, MCP where applicable, and relevant validation. It is not a claim of Adobe rendering equivalence.

- [ ] Module layout: central canvas, Navigator/presets/history left, histogram/tools/adjustments right, full-width filmstrip, hideable panels.
- [ ] Bounded reusable RAW processing cache, cancellation, fit and detail previews.
- [ ] Rendering process version with legacy preservation and explicit upgrade.
- [ ] Parametric curves, primary calibration, global grading/blend/balance, incremental WB.
- [ ] Numeric controls, reset/nudge, gesture undo.
- [ ] Camera-profile import, compatibility and portable identity.
- [ ] Chroma/luminance detail controls and full-resolution inspection.
- [ ] Composed named local masks and overlays.
- [ ] Nondestructive healing and cloning.
- [ ] Direct crop/straighten/guided geometry.
- [ ] Culling shortcuts/advance, compare/survey, metadata undo.
- [ ] Catalog keywords/labels, paged import, offline records and root remapping.
- [ ] Read-only sidecar fallback and offline edit proxies.
- [ ] Display/proof color management and wider-gamut working/output path.
- [ ] Measured indexed photo catalog and disk preview management.
- [ ] Quality, memory and interaction benchmarks; separate packaged build.

Original files and the running application must remain untouched. Separate substantial research projects (sensor highlight reconstruction, AI sensor denoise, HDR/panorama/depth blur) remain explicitly outside a claim of completed parity.
