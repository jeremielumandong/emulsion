# Responsive starter layouts

The 154 supplied artwork templates remain unchanged. A separate **Responsive
layouts** category adds ten native starters: product overview, studio portfolio,
event schedule, course outline, team introduction, service packages, project
roadmap, travel guide, community update and research brief. The two earlier
additional starters also remain available.

These starters contain editable text and nested responsive frames. Cards stack
at narrow widths and use three columns from 760 pixels upward. Text reflows at
its authored font size. Frame backgrounds, spacing, colors, content and child
sizing can be edited with the same controls as hand-built layouts. No template
requires an AI provider or bundled font download.

The native size is 1200 × 1200. When making a narrow portrait copy, choose a page
height that accommodates its stacked content; resize diagnostics report artwork
outside the page. Responsive width preview preserves the chosen canvas height.
A responsive layout is not an instruction to shrink typography until everything
fits an arbitrary fixed rectangle.

The catalog, Home picker, editor drawer and MCP template listing share the same
source. Preview thumbnails are rendered from the actual authored responsive page
rather than creating a small page that accidentally activates a different layout.
`design_template_preview` in `emulsion-io` exports desktop/phone PNG and vector SVG
fixtures for visual review. Core regressions validate all ten layouts at three
widths, their native text/path sources and source preservation.
