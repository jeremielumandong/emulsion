# Tutorial: your first Design project

This tutorial builds a short presentation from a template, presents it, and
exports it as a PDF. It takes about fifteen minutes.

## What you'll make

A three-page widescreen deck with your own title text, a replaced photo and a
fade between pages, saved as an editable `.emu` project and exported as a
multi-page PDF.

## Prerequisites

- Emulsion is installed and running.
- A photo on your computer to place in the deck, such as a JPEG or PNG.

## Steps

1. **Start a Design project.** On Home, choose **Design**. In the
   **New document** dialog, make sure **Templates** is selected.
   You should see a grid of template previews and an **All templates** menu.

2. **Pick a presentation template.** Open the **All templates** menu and choose
   **Presentation**. Select a template, then choose **Create**.
   You should see the first slide on the canvas and one page in the page strip.

3. **Edit the title.** Double-click the title text and type your own title.
   Press Ctrl+Enter (Cmd+Enter on macOS) to finish editing.
   You should see the new title in the same font, size and color.

4. **Replace the photo.** Click a photo placeholder on the slide. Photo
   placeholders are frames with diagonal paint. If your template has none, open
   **Frames** in the left rail and choose **Rectangle frame** to add one. With
   the frame selected, open **Frames** and choose **Place / replace image…**,
   then pick your photo.
   You should see your photo cropped to the frame's shape.

5. **Add two more pages.** Open **Design** in the left rail, choose
   **Explore templates**, and open the **Presentation** category. Click two
   templates.
   You should see three pages in the page strip, each at its template's size.

6. **Add a page transition.** Select the second page in the page strip. Choose
   **Animate** in the canvas toolbar, open **Page transition: None**, and choose
   **Fade**. Repeat for the third page.
   You should see the button read **Page transition: Fade**.

7. **Present the deck.** Select the first page, then choose **Present** in the
   canvas toolbar. Press the Right arrow key to move to the next page. Press
   Escape to stop.
   You should see pages two and three fade in, and then the editor returns to
   the first page.

## Save and export

1. Choose **File → Save**, name the project, and save it.
   You should see the project name in the document tab. The file is an `.emu`
   project that keeps every page editable.
2. Choose **File → Export…**. Under **Project export**, open
   **Pages, vectors and presentations…** and choose **Print PDF · all pages**.
3. Pick a destination file.
   You should see a status message that three pages were exported. Open the PDF
   to check that each slide is one page.

To hand the deck to someone who uses PowerPoint, choose
**Editable PowerPoint · all pages** from the same menu instead.
