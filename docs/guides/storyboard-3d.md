# Storyboard 3D and Shot Generator

Phase 11 adds 3D sets to the Storyboard workspace, in the spirit of
Storyboarder's Shot Generator: place posable mannequins and props, choose a
lens, shot size and angle, light the set, and render a toon reference to draw
over. This guide describes the engine in the `emulsion-scene` crate, which the
Shot Generator view, snapshots, exports and MCP tools all share. The UI
sections will be added as the Shot Generator view lands.

Everything here works offline. The mannequins and props are generated by
Emulsion itself; no third-party models are bundled.

## Sets

A set (a `Scene`) holds objects, one shot camera and an environment.

- **Units and axes.** Metres, Y up, the ground is the plane y = 0. Objects
  face +Z when unrotated, so a character's left hand points toward +X.
- **Objects** are characters, props and lights. Each has a stable id (never
  reused, even after deletion), a name, a transform (position; rotation as
  yaw/pitch/roll in degrees or an exact quaternion; per-axis scale), a
  visibility flag and a base colour.
- **Environment:** sky and horizon colours, ground colour, ground on/off,
  grid on/off and spacing, horizon line on/off and ambient light.
- **Limits:** 256 objects, 2 million triangles after tessellation, 64 MB and
  1 million triangles per imported model.

Sets are plain JSON. Fields that are missing take their defaults, so older
or hand-written files load; unknown fields are ignored. A minimal set:

```json
{
  "objects": [
    { "id": 1, "name": "Mia", "type": "character",
      "body": { "kind": "adult_female" },
      "pose": { "name": "my pose", "joints": { "head": { "y": 10 } }, "right_hand": "point" },
      "face": "happy",
      "transform": { "position": [0, 0, 0], "rotation": { "yaw": 20, "pitch": 0, "roll": 0 } } },
    { "id": 2, "name": "Table", "type": "prop", "source": "builtin", "kind": "table",
      "transform": { "position": [0, 0, 1.2] } },
    { "id": 3, "type": "light", "kind": "key", "intensity": 0.9,
      "transform": { "rotation": { "yaw": 35, "pitch": -50, "roll": 0 } } }
  ],
  "camera": { "position": [0, 1.6, 5], "yaw": 180, "focal_length_mm": 35 }
}
```

## Mannequins

Four body types: **adult male**, **adult female**, **adult** (neutral) and
**child**. Sliders:

| Slider | Range | Effect |
| --- | --- | --- |
| Height | 0.5–2.5 m | Overall height (default 1.78 / 1.65 / 1.72 / 1.20 m) |
| Build | 0–1 | Slim to heavy: limb and torso thickness |
| Head size | 0.7–1.5 | Head height multiplier (children already have larger heads) |
| Leg length | 0.8–1.2 | Longer legs, shorter torso; height stays the same |
| Arm length | 0.8–1.2 | Arm length |
| Shoulder width, hip width | 0.7–1.4 | Shoulder and hip spacing |

The figure is built from ellipsoids and tapered capsules attached rigidly to
a 31-bone skeleton: hips, spine, chest, neck, head; per side a shoulder,
upper arm, lower arm, hand, thumb (2 joints), index finger (2 joints), the
other fingers as one group (2 joints), upper leg, lower leg and foot. A small
nose shows which way the head faces.

With **ground lock** (on by default) the figure is lifted or lowered so its
lowest point rests on the ground, whatever the pose.

## Posing

### Joint rotations

Each joint stores three angles in degrees. Every bone's rest frame lines up
with the character (X = its left, Y = up, Z = forward), so the numbers read
the same on every bone:

| Bone | `x` | `y` | `z` |
| --- | --- | --- | --- |
| Spine, chest, neck, head | + bends forward | + turns left | + leans right |
| Left upper arm or leg | − swings forward | twist | + raises outward |
| Left lower arm | − bends the elbow | twist | — |
| Lower leg | + bends the knee | — | — |
| Left fingers | — | — | − curls |

Right-side bones mirror the left: their `y` and `z` signs flip. Angles are
applied as twist first, then side swing, then front/back swing. Every joint
has limits (an elbow only bends one way, the head turns at most about 95°
with the neck); values outside are clamped.

### Poses, hand shapes and faces

A pose is data: joint angles (bones not listed stay at rest), a hips offset in
units of figure height (so one pose fits a child and an adult) and a hand
shape per hand. Poses can be **mirrored**, **blended** (joints interpolate;
hand shapes switch at the midpoint) and saved as custom poses in JSON.

Built-in poses: stand, relaxed stand, walk, run, sit, sit on floor, kneel,
crouch, point, wave, reach, arms crossed, hands on hips, fight stance, fall,
lie down, phone call, carry.

Hand shapes: open, relaxed, fist, point, grip.

Faces are drawn as lines on the head in the toon, clay and outline styles:
neutral, happy, sad, angry, surprised, scared, or blank.

### IK and look-at

- **Two-bone IK** moves a wrist or ankle to a target in the world. Elbows and
  knees are true hinges and bend toward a pole direction (elbows back and
  out, knees forward by default); when the preferred bend would break a
  shoulder or hip limit, the closest bend that respects it is used. Feet keep
  their orientation, so they stay flat.
- **Look-at** turns the neck and head toward a point; the neck takes about
  40% of the turn.
- IK targets and look-at live on the character until **baked** into the pose.

## Props

Built-in props are sized by width × height × depth in metres and sit on the
ground with their front toward +Z:

| Prop | Default size (m) | Options |
| --- | --- | --- |
| Box, cylinder, sphere | 0.5 × 0.5 × 0.5 (cylinder 1 m tall) | |
| Wall | 4 × 2.6 × 0.15 | |
| Floor | 6 × 0.02 × 6 | |
| Door | 0.9 × 2.1 × 0.12 | Opening angle |
| Window frame | 1.2 × 1.2 × 0.1 | |
| Table | 1.4 × 0.75 × 0.8 | Round top |
| Chair | 0.45 × 0.9 × 0.45 | |
| Bed | 1.6 × 0.9 × 2.1 | |
| Sofa | 2 × 0.85 × 0.9 | |
| Car | 1.8 × 1.45 × 4.5 | |
| Tree | 3 × 6 × 3 | |
| Lamp post | 0.4 × 4.5 × 0.4 | |
| Stairs | 1 × 1.44 × 2.4 | Number of steps |

### Imported models

- **glTF 2.0** (`.gltf` with embedded or neighbouring buffers, and `.glb`):
  triangle meshes, node transforms, base colours, double-sided materials and
  **skins**. A skinned model can be posed by joint name, with the same
  three-angle joint rotations as mannequins.
- **OBJ:** vertices, normals and faces of any size; each `o`/`g` group becomes
  a named part.
- Not supported: textures, animations, morph targets, sparse accessors and
  compressed meshes (Draco, meshopt). A file that needs them is refused with
  a message. USDZ and FBX are not supported.
- Buffers referenced by a `.gltf` must sit in the same folder or below it.
- A set that names a model which is not available shows a placeholder box.

## Cameras and lenses

- The camera has a position, yaw, pitch and roll, a **focal length** in mm
  and a **film back** (sensor size; Super 35, 24.89 × 18.66 mm, by default;
  full frame and Super 16 are presets).
- The film back's width sets the horizontal field of view:
  `hfov = 2 · atan(width / (2 · focal length))`. A 35 mm lens on Super 35
  sees about 39° across; 50 mm on full frame about 40°. The board's aspect
  ratio sets the vertical extent.
- Common primes for pickers: 14, 18, 24, 35, 50, 65, 85, 100 and 135 mm.
- **Top, side and front views** are orthographic cameras fitted to the set,
  for positioning objects.

### Shot sizes

Framing a shot keeps the lens and moves the camera so the subject fills the
frame from the top of the head (plus 12% headroom) to the size's cut line:

| Size | Shows |
| --- | --- |
| ECU — extreme close-up | The eyes, centred |
| CU — close-up | Head and the top of the shoulders |
| MCU — medium close-up | Head to mid-chest |
| MS — medium shot | Head to the waist |
| MWS — medium wide (cowboy) | Head to the knees |
| WS — wide shot | The whole figure |
| EWS — extreme wide shot | The figure small in the set |

Cut lines follow the posed skeleton, so a seated or crouching character is
framed by its own body. Props are framed by their bounding size. A shot can
also frame one body part (a hand, the face or a foot), or a whole group of
characters.

### Angles and sides

- **Angles:** eye level, low, high, bird's eye, worm's eye, dutch (rolled),
  over the shoulder (behind a second character's shoulder toward the
  subject) and two-shot (both characters, seen side on).
- **Sides**, relative to where the subject faces: front, three-quarter left
  and right, left and right profile, behind left and right, and behind.

### Shot Explorer

Given a subject, the Shot Explorer proposes varied setups, mixing size, angle,
side and a lens suited to the size (from 18 mm for extreme wide to 100 mm for
extreme close-ups), each with a name such as "Low-angle close-up, three-quarter
left". Over-the-shoulder and two-shots are included when there is another
character. The list is the same every time for the same set.

## Rendering

The renderer runs on the CPU and draws any size, with a transparent
background if wanted.

| Style | Look |
| --- | --- |
| Toon | Object colours in 2 or 3 light bands with contour lines |
| Clay | Smoothly shaded grey with contour lines |
| Outline | Lines only on white, for tracing |
| Silhouette | Solid black shapes |

- Contour lines come from object edges, depth jumps and creases (normal
  changes above 40° by default). Line width, colour and crease angle are
  adjustable; a selected object's lines can be drawn in a highlight colour.
- Lighting: key, fill and rim lights are directional and shine along their
  forward direction; ambient light comes from the environment.
- The ground, a grid that fades with distance and a horizon line are drawn
  behind the set.
- Supersampling (2–4×) smooths edges for snapshots.
- Output is identical on every run and thread count.

A three-character, ten-prop set (about 19,000 triangles) renders at 960 × 540
in roughly 30–40 ms on four cores in release builds.

## Describe a shot

Type a shot in words and Emulsion builds the set, poses the characters and
frames the camera. Examples:

- "low-angle close-up of two people at a table"
- "wide shot of a woman running down a street"
- "over-the-shoulder of Mia talking to Tom"
- "bird's eye view of a car"
- "extreme close up of a hand"
- "high angle wide shot of a family of three in a park"
- "dutch angle cowboy shot of two angry men fighting, 85mm"

The parser recognizes these kinds of words (the longest phrase wins, so
"extreme close up" beats "close up"):

| Kind | Examples |
| --- | --- |
| Shot size | extreme close up, ECU, close-up, medium close up, medium shot, cowboy shot, wide shot, full shot, establishing shot |
| Angle | eye level, low angle, high angle, bird's eye, overhead, worm's eye, dutch, over the shoulder, two shot |
| Side | from behind, profile, three quarter, front view |
| Lens | 35mm, 85 mm, wide angle, telephoto, fisheye |
| People | a man, two women, three people, a child, kids, a couple, a family (of four) |
| Names | any capitalized unknown word: "Mia", "Tom" |
| Actions | running, walking, sitting, kneeling, crouching, pointing, waving, reaching, fighting, falling, lying down, on the phone, carrying, arms crossed, hands on hips, talking |
| Moods | happy, sad, angry, surprised, scared (and synonyms) |
| Props | table, chair, car, tree, door, window, bed, sofa, stairs, lamp post, box, wall |
| Places | street, room, office, kitchen, park, forest |
| Body parts | hand, face, eyes, foot |
| Relations | talking to, facing, looking at, on the floor |

How the set is built:

- People sit at a table on chairs, facing each other across it.
- Two people talking to each other face each other; without an angle they get
  a two-shot.
- Other groups stand in a row and are framed together in wide and medium shots.
- A street adds a road, building walls and lamp posts; a room adds a floor and
  walls; a park adds trees.
- When no person is mentioned, the first prop is the subject ("a car").
- Words the parser does not know are listed, so the assistant can refine the
  set through MCP.

## For integrators

The `emulsion-scene` crate has no UI. The main entry points:

- `Scene` with gizmo-friendly setters: `translate`, `rotate_about`,
  `set_scale`, `set_joint`, `set_ik_target`, `bake_pose`; `validate`,
  `normalize`, `to_json` and `from_json`.
- `prepare(scene, assets)` returns a `PreparedScene`; keep it while only the
  camera changes.
- `render(prepared, camera, w, h, options)` and the one-call
  `render_to_rgba(scene, assets, w, h, style)` return straight-alpha RGBA8.
- `pick` (object and bone or joint under a pixel), `pick_joint` and
  `joint_handles` (posing handles), `project_point` (attaching 2D layers to
  models), `attachment_matrix` and `SurfaceFrame` (layers on model
  surfaces).
- `frame_shot`, `explore_shots`, `text_to_shot` and `parse_shot`.
- `import_file` and `import_bytes`, with models kept in an `AssetLibrary`.
